# 🎓 CampusEcho - Feedback Intelligence System

## 📌 Overview

CampusEcho is an AI-powered anonymous feedback management platform designed for educational institutions. The system enables students to submit feedback securely and anonymously while providing administrators with intelligent sentiment analysis, issue prioritization, and automated recommendations.

The platform leverages AWS services and Natural Language Processing (NLP) to transform student feedback into actionable insights.

## ⚙️ How It Works

1. Student submits anonymous feedback.
2. Feedback is securely stored in AWS.
3. Amazon Comprehend performs sentiment analysis.
4. The system categorizes feedback automatically.
5. Priority issues are identified.
6. AI generates recommendations.
7. Administrators view reports through the dashboard.
